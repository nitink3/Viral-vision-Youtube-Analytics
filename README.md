# 📊 VIRAL VISION: The Science Behind Social Media Performance

## 📌 Project Overview
VIRAL VISION is an Excel-based data analytics project that explores historical YouTube trending videos to understand how video categories, views, and audience engagement relate to performance.

The project uses data cleaning, analysis, and visualization to turn raw data into meaningful insights.

## 🎯 Business Objective
To analyze historical YouTube trending-video data and identify patterns in video views and engagement across different content categories.

## 🛠️ Tools & Skills
- Microsoft Excel
- Power Query for data cleaning and transformation
- PivotTables and PivotCharts
- Data visualization and dashboard design
- Correlation analysis
- Data storytelling

## 📈 Key Findings
- **Music:** Showed the highest average views in this analysis.
- **Engagement:** Average engagement rates varied across categories.
- **Views vs. Engagement:** The correlation was approximately **-0.041**, indicating a negligible negative linear relationship in the analyzed data.
- **Key Insight:** A video receiving more views does not necessarily mean it has a higher engagement rate.

## 📐 Engagement Rate
For this project, engagement rate is calculated as:

**Engagement Rate = (Likes + Comments) ÷ Views × 100**

This is the project's chosen measure of engagement, not an official universal YouTube metric.

## 🔍 Methodology
1. Imported the historical YouTube trending-video dataset.
2. Cleaned and transformed data using Power Query.
3. Connected video category IDs to category names.
4. Analyzed views and engagement using PivotTables.
5. Created charts and a dashboard to communicate findings.
6. Examined the relationship between views and engagement.

## 📊 Project Deliverable
**Excel Workbook:** `Viral_vision_Youtube_analytics.xlsx`

The workbook contains the analysis, visualizations, and dashboard developed for this project.

## 📂 Data Source
The project uses the historical US YouTube trending-video dataset from Kaggle.

[View the YouTube Trending Video Dataset on Kaggle](https://www.kaggle.com/datasets/datasnaek/youtube-new)

## ⚠️ Limitations
- The dataset represents historical trending-video records, not all YouTube videos.
- The same video may appear on multiple trending dates.
- Correlation does not establish causation.
- Findings describe this dataset and should not be generalized to all YouTube content.
